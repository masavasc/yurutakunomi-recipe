# ゆる宅飲み レシピ検索

GitHub Pages向けの静的Webアプリです。サーバーやデータベースは不要です。

## 既存サイトの更新（お気に入り・最近見た版）
既存リポジトリの `index.html`、`app.js`、`style.css` を、この版の3ファイルで同時に上書きしてください。ZIPには全6ファイルが入っているため、展開して全ファイルを上書きしても構いません。ZIP自体をアップロードする必要はありません。

`recipes.js` は取得した最新版とバイト単位で同一の279件です。`manifest.webmanifest` も変更していません。`noindex, nofollow` を維持しています。

## お気に入り・最近見た
- 各行の☆で登録、★で解除。星の操作では公式ページを開かず、履歴にも追加しません。
- 「★ お気に入り」は登録件数を表示し、押すとお気に入り一覧へ切り替わります。
- 料理名のリンクを開くと「最近見た」へ追加します。最新順で10件まで、再度開いたものは先頭に移動します。
- 「最近見た」を押すと履歴一覧へ切り替わります。
- 同じ一覧ボタンを再タップするか「通常検索」で検索結果に戻ります。検索条件は保持されます。
- 保存一覧では検索条件を適用せず、一覧をすべて表示します。分類・食材・キーワードを操作すると、通常検索へ戻り、その条件で検索します。
- お気に入りと履歴は同じブラウザのlocalStorageに保存されます。別端末・別ブラウザには同期されません。ブラウザのサイトデータを消すと保存内容も消えます。
- 保存できない環境では案内を表示し、そのページを閉じるまでの間は利用できます。
- 通常のタップ、キーボードのEnter、Ctrl/Commandクリック、中クリックによるリンク操作を記録します。ブラウザの長押し・右クリックメニューからの「新しいタブで開く」は取得できません。公式サイト側の読み込み完了までは確認しません。

ローカルHTTP配信でMicrosoft Edgeを使用し、279件表示、複合検索、モード切替、お気に入り登録・解除・再読み込み、12件開いた際の履歴10件制限・再閲覧順序・永続保存、壊れた保存データ・保存不可への対応を確認しました。幅320 / 390 / 768pxで横はみ出しがないこと、390pxの画面表示、JavaScriptエラーがないことも確認済みです。公式リンク先への遷移テストでは外部ページの応答をテスト用に置き換えています。iPhone実機では未確認です。

## 公開手順
1. GitHubで新しいリポジトリを作成します（例: `yurutakunomi-recipe`）。
2. このフォルダ内のファイルをすべてリポジトリ直下へアップロードします。
3. GitHubの **Settings → Pages** を開きます。
4. **Build and deployment → Source** を `Deploy from a branch` にします。
5. Branchを `main`、Folderを `/(root)` にして **Save**。
6. 数分後に表示されるGitHub PagesのURLをiPhone/iPadで開きます。
7. Safariの共有ボタン → **ホーム画面に追加** でアプリ風に起動できます。

## ファイル
- `index.html` — 画面
- `style.css` — Scientific / Clinical Database調のスマホUI
- `app.js` — 大分類・料理タイプ・食材・キーワード検索、お気に入り・最近見た
- `recipes.js` — 279件のレシピデータ
- `manifest.webmanifest` — ホーム画面追加/PWA用設定

## 検索仕様
- 大分類：チップを1回タップで選択、同じチップを再タップで解除
- 料理タイプ：同様
- 食材：部分一致
- 下段検索：料理名・分類・食材・検索テキストを横断検索
- 条件はAND検索
- レシピをタップすると公式レシピURLを新しいタブで開きます
