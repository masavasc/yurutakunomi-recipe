## 既存GitHub Pagesの更新

1. ZIPをダウンロードし、展開します。
2. 展開した全6ファイルを既存リポジトリの同じ場所に上書きします。
3. GitHubにコミット・プッシュします。ZIPそのものをアップロードする必要はありません。
4. Pagesへの反映後、サイトを再読み込みします。古い画面が残る場合はPCで Ctrl+F5 を押します。

公開先URLを変えず、同じブラウザを使えば、お気に入りと最近見た履歴を引き継げます。保存内容は端末やブラウザ間では同期されません。

## ファイル

- `index.html`：画面
- `style.css`：暖色系のスマホ・タブレット対応デザイン
- `app.js`：複合検索、お気に入り、最近見た、旧URLの移行
- `recipes.js`：651件のレシピ検索データ
- `manifest.webmanifest`：ホーム画面追加用設定
- `README.md`：更新内容・使い方

## 使い方

- レシピ集、大分類、料理タイプはボタンをもう一度押すと解除できます。
- 食材欄とキーワード欄は、ほかの選択条件とAND検索します。
- 料理名を押すと公式ページが新しいタブで開き、「最近見た」に追加されます。
- ☆でお気に入りに保存、★で解除します。
- 保存一覧では全保存項目を表示し、検索条件を操作すると通常検索に戻ります。
- 最近見たは新しい順に最大10件です。
- 長押しや右クリックメニューからの別タブ表示は履歴に記録できません。
- ブラウザのサイトデータを削除するとお気に入りと履歴も消えます。
