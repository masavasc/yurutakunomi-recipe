## お気に入り・最近見た

同じサイトURL・同じブラウザの保存データは、読み込み時に旧URLから新しい個別URLへ自動変換します。重複を除き順番を保持します。別端末・別ブラウザには同期しません。保存不可の環境では画面に案内を表示し、今回の操作中のみ保持します。

料理名を押すと公式レシピを新しいタブで開きます。最近見たは新しい順に10件までです。☆でお気に入り登録、★で解除します。
